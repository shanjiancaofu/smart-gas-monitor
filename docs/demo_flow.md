# 课设演示流程

1. 上电后确认 OLED 显示 MQ4、MQ6、MQ7 的 ADC 值、状态和阀门状态。
2. KEY1 在实时页、设置页、历史页之间切换。设置页按 KEY5 选择 MQ4、MQ6、MQ7、采样周期或蜂鸣器时长。
3. KEY2 增加、KEY3 减少；参数修改后自动保存。断电重启后检查参数仍然存在。
4. 让 MQ6 模拟值超过阈值，观察 WARNING 进入 ALARM：红灯亮、蜂鸣器按报警通道数量发出节奏、继电器关闭、阀门指示灯熄灭。
5. 通过 USB-TTL 或 HC-05 发送 `STATUS?` 和 `HISTORY?`，确认状态和报警记录已经产生。
6. 将 MQ6 降回安全区并等待 3 秒。系统保持 SAFE_WAIT 和关阀状态，不自动开阀。
7. 按 KEY4 进行现场安全确认，确认 lockout 清除、阀门重新打开。
8. 需要快速演示时，长按 KEY5 约 1.5 秒进入测试模式。系统把 MQ6 采样值固定为 4095 ADC，自动走报警、蜂鸣器、继电器和历史记录链路；复位后退出测试模式。

历史记录只保存首次进入 ALARM 的事件，持续报警不会重复写入。蜂鸣器节奏和测试模式都不使用 HAL_Delay。
