# 串口协议

USART1（115200）和 USART2（9600）共用文本协议，8-N-1，每条命令以 CRLF 结束，命令不区分大小写。

```text
STATUS?
CONFIG?
HISTORY?
SET MQ4 2500
SET MQ6 2000
SET MQ7 2500
SET PERIOD 500
SET BUZZER OFF
SET BUZZER 5
SET BUZZER ALWAYS
VALVE CLOSE
```

协议不提供远程开阀。`VALVE OPEN` 返回 `ERR ONLY CLOSE`，lockout 只能在环境连续安全 3 秒后由现场 KEY4 解除。

```text
STATUS?
STATE=NORMAL VALVE=OPEN ALARMS=0
MQ4=840/2400 MQ6=710/2000 MQ7=900/2400

CONFIG?
TH MQ4=2400 MQ6=2000 MQ7=2400 PERIOD=100 BUZZ=5S
```

`HISTORY?` 按最新记录优先逐行返回序号、上电秒数、三路 ADC 和报警通道。没有 RTC，不返回日期时间。报警首次进入时两路串口主动发送 `ALARM` 行。
